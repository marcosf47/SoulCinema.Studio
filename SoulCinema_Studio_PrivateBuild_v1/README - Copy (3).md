# SoulCinema Studio — Private Build v1

A private launch-candidate build focused only on the approved SoulCinema pillars:

- SoulCinema Brand
- SoulCinema Originals
- SoulCinema Music
- SoulCinema Stories
- SoulCinema Live
- SoulCinema Studio

The build includes the real `Mwen Poukont Mwen` audio, official artwork, a cinematic hero, and a private video-comparison room.

## Local review

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Private launch

Deploy to Vercel without public announcement. Add the domain only after the preview is approved.
