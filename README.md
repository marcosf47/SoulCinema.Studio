# SoulCinema Studio — Sprint 2 Experience Layer

Sprint 2 upgrades the deployable skeleton into a cinematic interactive experience.

## Included
- Cinematic session intro
- Animated hero portal and atmospheric grid
- Scroll-reveal motion system
- Active responsive navigation
- Image-driven Grand Lobby rooms
- Full-screen Cinema Mode player
- Enhanced Films gallery
- Enhanced Music Room and audio interactions
- vMix/YouTube-ready Live Room experience
- Reduced-motion accessibility
- Mobile responsive polish

## Run
```bash
npm install
npm run dev
```

## Production test
```bash
npm run build
```

## Live configuration
Set `NEXT_PUBLIC_YOUTUBE_LIVE_ID` in Vercel to the YouTube video ID receiving the vMix stream.
